# Abdulhadi Fatani’s personal website

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Astro, Tailwind CSS, and strict TypeScript, selected by the owner. Static output with npm and no server-side services.

## Product Purpose

Establish an initial personal website for Abdulhadi Fatani (عبدالهادي فطاني). Visitors can navigate Home, Projects, Blogs, and About in English or Arabic. Each page currently contains only a construction message.

## Capabilities and Constraints

- English is the initial language; Arabic has separate `/ar/` URLs and right-to-left layout.
- Language switching retains the current section. Remember explicit language choices for future visits to the root URL; deep links retain their URL language.
- Support light and dark themes, initially following the operating system and remembering a manual selection.
- Keep navigation and content usable without JavaScript. Browser persistence is optional enhancement.
- Implement and validate locally. Hosting and publication are excluded from this task.
- Do not invent project entries, posts, biography, or other personal claims.

## Brand Commitments

Use the supplied `styling_guide/kit/` without modifying it, including its IBM Plex English and Arabic fonts, semantic theme tokens, and applicable component styles.

## Accessibility & Inclusion

Use semantic navigation, current-page identification, translated control labels, keyboard focus indicators, comfortable touch targets, and responsive layouts for both text directions.
